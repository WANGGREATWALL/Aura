# B0：构建修复与生产/测试库隔离

日期：2026-10-20（北京时间）。源码基线 `aa3b3ae`，本轮尚未提交。对应整改项 R14、R27、X11；完整范围见 [整改计划](../flow_remediation_plan.md)。

## 改动

- 正常 `aura` 不再因打开测试而带故障注入宏；需要钩子的测试链接独立 `aura_testing`，benchmark 与生产消费者仍链接 `aura`。
- 两种库通过相同的 target 配置函数管理源码、语言标准、PIC/visibility、平台依赖和可选 OpenCL，避免复制后配置漂移。
- Android 不再手写链接 pthread；线程依赖使用 `Threads::Threads`，动态加载使用 `CMAKE_DL_LIBS`，Android 追加 android/log。
- Aura 作为子项目时自身测试默认关闭；不创建或强制覆盖父工程的 BUILD_TESTING；AURA_BUILD_TESTS 支持显式启用，父工程 BUILD_TESTING=OFF 仍禁止测试。
- 新增生产 C API 消费者及生产 archive 符号检查；故障测试变体保留既有故障用例。
- 本轮没有改动 flow 状态机、队列、tiled、线程退休或公开结果布局。

## 已运行的验证

环境：Linux x86_64，GCC 14.2.0，CMake 3.31.6，Ninja 1.11.1.4，允许 CPU 数 5。

| 配置 | 结果 |
| --- | --- |
| 默认 Debug / CPU-only | 构建成功；154/154 单测（16 suites）；10/10 CTest 通过 |
| Debug / ENABLE_OPENCL=ON | 构建成功；167/167 单测（17 suites）；13 项 CTest 通过、1 项真实 GPU 明确 skipped |
| Release / BUILD_TESTING=OFF / benchmark ON | 构建成功，无 aura_testing 或故障注入宏；生产符号检查通过；现有 host benchmark 正常退出 |
| 父工程 BUILD_TESTING=ON，默认嵌入 Aura | 未生成 Aura 自身测试/变体；生产库和 C API 消费者实际构建、运行通过 |
| 父工程未定义 BUILD_TESTING | 配置通过，Aura 没有创建父级 BUILD_TESTING 选项，未默认生成自身测试 |
| 编译命令隔离 | CPU 的 28 个、OpenCL 的 33 个正常库对象均无 AURA_FLOW/MM/GPU_TESTING；测试变体含相应钩子宏 |
| 符号检查负对照 | 同一检查脚本能拒绝 aura_testing，预期拒绝结果已验证 |
| 严格接口语法 | C11 与 C++11 的 -Wall -Wextra -Werror -pedantic 检查通过 |
| git diff --check | 通过 |

真实 GPU skipped 是无可用 OpenCL platform，不是完成设备计算验证。本轮没有新运行 ASan/LSan/TSan；既有记录不作为本轮新证据。

## 复跑命令

```sh
export PATH=/workspace/.cloud-tools/bin:$PATH
cmake -S /workspace/Aura -B /workspace/.cloud-build/flow-b0-cpu -G Ninja \
  -DCMAKE_BUILD_TYPE=Debug -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build /workspace/.cloud-build/flow-b0-cpu --parallel 4
ctest --test-dir /workspace/.cloud-build/flow-b0-cpu --output-on-failure
(cd /workspace/.cloud-build/flow-b0-cpu && ./aura_test --gtest_brief=1)

cmake -S /workspace/Aura -B /workspace/.cloud-build/flow-b0-opencl -G Ninja \
  -DCMAKE_BUILD_TYPE=Debug -DCMAKE_EXPORT_COMPILE_COMMANDS=ON \
  -DENABLE_OPENCL=ON -DENABLE_OPENCL_HARDWARE_TESTS=ON
cmake --build /workspace/.cloud-build/flow-b0-opencl --parallel 4
ctest --test-dir /workspace/.cloud-build/flow-b0-opencl --output-on-failure
(cd /workspace/.cloud-build/flow-b0-opencl && ./aura_test --gtest_brief=1)

cmake -S /workspace/Aura -B /workspace/.cloud-build/flow-b0-release -G Ninja \
  -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF -DENABLE_FLOW_BENCHMARKS=ON \
  -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build /workspace/.cloud-build/flow-b0-release --parallel 2
(cd /workspace/.cloud-build/flow-b0-release && ./flow_benchmark)

gcc -std=c11 -Wall -Wextra -Werror -pedantic -Iinc -fsyntax-only test/flow_c_api.c
g++ -std=c++11 -Wall -Wextra -Werror -pedantic -Iinc -Isrc -fsyntax-only test/flow_cxx11.cpp
```

最后两条从 Aura 根目录执行。父工程验证工程位于当前环境 `/tmp/flow-b0-parent`，包含 BUILD_TESTING 已定义与未定义两种配置；生产库构建和消费者运行在前者执行。原始配置/构建/测试日志、主机 metadata 与代码 SHA256 保存在当前环境 `/workspace/.cloud-build/flow-validation/B0-2026-10-20/`，不是 Android 设备报告。
